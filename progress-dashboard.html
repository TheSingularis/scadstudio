Where things stand: the core edit loop is real and working — open a file, edit it live, click between code and 3D shapes in either direction, drag a shape with a translate/rotate/scale gizmo to rewrite its source in place (inserting a new wrap if it had none, and doing so "in place" relative to any existing translate rather than orbiting the world origin), or insert a new primitive from the toolbar. Every top-level statement in a file is its own independently-rendered, clickable, draggable object.

Known gaps (expected, not bugs): no parameter panel yet for editing a selected node's own arguments directly (rest of M5), mirror/color aren't wired to the toolbar, no booleans/extrusions UI (M6-M7), no custom-module detection (M8). Selection is positional and can reset after a structural edit (a stable-ID fingerprint comes later, once multi-node dragging needs it). Combined multi-axis rotation hasn't been checked against OpenSCAD's own composition order (only single-axis rotation is verified).

Full history: see PLAN.md's per-milestone "build notes" sections in the repo for exact bugs found/fixed at each step.
