# ScadStudio brand

<img src="logo.svg" alt="ScadStudio logo" width="96" height="96">

## The mark

An amber part with a round cut taken out of its corner, and the cutter drawn as a dashed blue circle. It is the first thing most people model in OpenSCAD, `difference() { cube(...); cylinder(...); }`, with the cutter shown the way the `%` ghost modifier shows it. The cut follows the outer edge of the dashed circle, so the two never overlap.

| File | Use |
| --- | --- |
| [`logo.svg`](logo.svg) | The mark. Use this wherever SVG works. |
| [`logo-512.png`](logo-512.png) | 512 × 512 PNG with a transparent background, for places that need a bitmap. |
| [`social-preview.png`](social-preview.png) | 1280 × 640 image for the GitHub social preview (repository Settings → General → Social preview). |

The mark works on light and dark backgrounds without changes. Keep some clear space around it (about a quarter of its width), and don't recolor, stretch, rotate or outline it.

## Name

- **ScadStudio**, one word with two capitals, in prose, docs and headings.
- **scadstudio**, lowercase, where a lowercase identifier is expected: the repository, the executable and the download file names.

ScadStudio is an independent project. Don't use OpenSCAD's own logo next to the ScadStudio mark in a way that suggests the two are the same project or that OpenSCAD endorses this one.

## Tagline

> Your model is the source code.

One-line description: *ScadStudio is a desktop CAD editor where you click, drag and sketch parts in a 3D viewport, and every change is written back as plain, readable OpenSCAD.*

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Part amber | `#E8A33D` | The mark's part; the app's selection color. |
| Ghost blue | `#4A90D9` | The mark's cutter; the app's default mesh color. |
| Ink | `#18181B` | Wordmark and headings on light backgrounds. |
| Graphite | `#52525B` | Secondary text. |
| Paper | `#FAFAFA` | Light background. |

Amber and blue are the same colors the app already uses for selected and unselected parts, so the brand and the UI match.

## Type

- **Archivo ExtraBold** (800) for the wordmark and display headings.
- **Fira Code** for code and the tagline.
