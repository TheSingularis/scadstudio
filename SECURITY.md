# Security policy

ScadStudio is in beta. Only the latest release on the [Releases page](https://github.com/TheSingularis/scadstudio/releases) gets fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what an attacker could do, the ScadStudio version, your OS, and the steps or file that trigger it.

Things that are in scope include a `.scad` file that makes ScadStudio read or write files outside what the user chose, or run code, when it is opened.
